# テスト専用変更の昇格記録

Preview → main の累積昇格にテスト専用 PR が含まれる場合は、昇格 PR 本文にその PR が本番実行経路を変更しないことを 1 行で記録する。

記録例:

```text
- #1234 <HEAD_SHA> — test-only / 本番実行コード・設定・依存関係の差分なし / Preview 実経路ゲート追加なし
```

この分類は、差分がテストだけで、本番実行コード・設定・依存関係・DB schema/migration・workflow を変更していない場合にだけ使う。対象外であることを理由にレビューや CI の証跡を省略してはならない。

累積 release-unit の別 PR が `docs/QA.md` の Preview 実経路ゲート対象なら、その必須項目は通常どおり累積変更全体に対して実行する。テスト専用 PR の記録は、他の構成 PR が要求する実経路確認を免除するものではない。
