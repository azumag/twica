# 反復抑制抽選の条件付き相関

`src/lib/gacha.ts` の `selectWeightedCardMinimizingRepeat` は、設定された長期排出率を維持しながら、直前と同じカードが続く確率を理論上可能な最小値まで下げるための抽選です。

この方式が保証するのは、主に次の2点です。

- 固定されたカードプールでは、各カードの**長期の周辺分布**が設定重みに一致すること
- 直前カードとの**即時反復率**が理論下限 `max(0, 2 * maxProbability - 1)` になること

一方で、`次のカード | 直前のカード` という**条件付き遷移確率が一様になることや、連続する抽選が独立になることは保証しません**。これは現行方式の既知の性質であり、即時反復の抑制と長期排出率の維持を優先した結果です。

## なぜ条件付き相関が残るか

実装は、正の重みを持つカードをカードID順に並べ、その重みを円周上の区間として配置します。直前カードの区間から一様に点を選び、最大区間の重み `M` と総重み `T` から決めた安全な距離だけ円周上を移動し、移動先の区間を次カードとします。

移動距離は `[min(M, T-M), max(M, T-M)]` から一様に選びます。この操作は円周全体で見た一様性を保つため、定常状態では次カードの周辺分布を元の設定重みに保てます。しかし、直前カードを固定して見ると、移動元区間と移動距離の組み合わせによって到達しやすい区間と到達しにくい区間が生じます。

## 均等4枚の例

カード `A / B / C / D` がすべて同じ重みの場合、各カードの長期排出率は25%で、同じカードの即時反復は0%になります。

ただし、直前が `A` のときの次カードは概ね次の分布になります。

| 次カード | 条件付き確率 |
| --- | ---: |
| A | 0% |
| B | 25% |
| C | 50% |
| D | 25% |

`B`、`C`、`D` が均等な `1/3` になるわけではありません。直前カードが変わればこの形もカードID順に回転します。

この相関があっても、直前カード自体が25%ずつ現れる定常状態で全遷移を合算すると、次カードの周辺分布は `A / B / C / D = 25% / 25% / 25% / 25%` のままです。

したがって、小さいプールでは「同じカードは続かないが、特定の飛び方がやや多い」という別種のパターンとして体感される可能性があります。これは現在の契約違反ではありません。

## 最大重みが50%を超える場合

最大カードの確率を `p` とすると、`p > 0.5` では、そのカードの即時反復を完全に0へ落としながら同じ長期排出率を維持することはできません。現行方式では不可避な重なりだけを残し、全体の反復率を `2p - 1` まで下げます。

最大重みが50%以下なら、全カードで即時反復を0にできます。それでも、上の均等4枚の例のような条件付き相関は残り得ます。

## フォールバック時の扱い

次の場合は反復抑制の条件付き遷移ではなく、従来の独立な重み付き抽選へ戻ります。

- `previousCardId` が未指定の場合
- `previousCardId` が現在の正の重みを持つプールに存在しない場合
- 重み合計が有限値として扱えない異常な入力の場合

正の重みを持つカードが1枚しかない場合は、反復を避ける方法がないためそのカードを返します。

## テスト・将来変更時の注意

現行方式を検証するときは、次の性質を別々に扱います。

1. 長期の周辺分布が設定重みに一致すること
2. 即時反復率が理論下限になること
3. 条件付き遷移には相関があり得ること

1と2を満たすことから、3の「各遷移先も均等・独立である」と推論してはいけません。逆に、条件付き遷移の偏りだけを理由に、長期排出率が壊れているとも判断しません。

将来、短周期やペア相関の体感をさらに減らす必要が出た場合は、長期周辺分布と反復率の理論下限を維持できる別の結合方式（最大エントロピー結合など）と比較し、遷移行列を測定したうえで変更します。追跡先は Issue #1302 です。
