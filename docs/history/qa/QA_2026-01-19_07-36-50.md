## 問題点

### 1. テストが失敗している（Critical）

**ファイル**: `tests/unit/security-headers.test.ts:36-46`

**問題点**:
本番環境のCSPテストが失敗しています。

```typescript
it('本番環境ではlocalhostへの接続を許可しない', () => {
  vi.stubEnv('NODE_ENV', 'production')
  const response = NextResponse.json({ test: 'data' })
  const result = setSecurityHeaders(response)
  const csp = result.headers.get('Content-Security-Policy')
  expect(csp).toContain('connect-src \'self\' https:;')  // ← 失敗
  expect(csp).not.toContain('localhost')
  expect(csp).not.toContain('unsafe-eval')
  expect(csp).not.toContain('unsafe-inline')  // ← 失敗
  vi.unstubAllEnvs()
})
```

**失敗の原因**:
1. テストが `connect-src 'self' https:;` を期待しているが、実装では `connect-src 'self' https: wss:;` となっている
2. テストが `unsafe-inline` を含まないことを期待しているが、実装では `script-src 'self' 'unsafe-inline'` となっている

**修正案**:
テストを更新し、新しいCSP設定を反映する：

```typescript
it('本番環境ではlocalhostへの接続を許可しない', () => {
  vi.stubEnv('NODE_ENV', 'production')
  const response = NextResponse.json({ test: 'data' })

  const csp = result.headers.get('Content-Security-Policy')
  expect(csp).toContain('connect-src \'self\' https: wss:;')
  expect(csp).not.toContain('localhost')
  expect(csp).not.toContain('unsafe-eval')
  expect(csp).toContain('unsafe-inline')
  vi.unstubAllEnvs()
})
```

### 2. 接続ステートのタイムアウト処理にクロージャの問題がある（Critical）

**ファイル**: `src/app/overlay/[streamerId]/page.tsx:102-107`

**問題点**:
`setTimeout` 内で `connectionStatus` を参照していますが、これはクロージャの問題があります。useEffectが実行された時点の `connectionStatus` を参照するため、常に最初の状態（'connecting'）を参照してしまいます。

```typescript
const timeoutId = setTimeout(() => {
  if (connectionStatus === 'connecting') {  // ← クロージャの問題
    setConnectionStatus('error');
    setErrorMessage('Connection timeout');
  }
}, 10000);
```

**影響**:
- 接続が成功しても、10秒後にタイムアウト処理が実行されてエラー状態になる可能性がある
- 接続ステートが正しく更新されない

**修正案1: useRefを使用する**
```typescript
const connectionStatusRef = useRef(connectionStatus);

useEffect(() => {
  connectionStatusRef.current = connectionStatus;
}, [connectionStatus]);

useEffect(() => {
  const cleanup = subscribeToGachaResults(streamerId, (payload) => {
    if (payload.type === 'gacha' && payload.card) {
      displayResult({
        card: payload.card as unknown as Card,
        userTwitchUsername: payload.userTwitchUsername,
      });
    }
  }, {
    onError: (error) => {
      setConnectionStatus('error');
      setErrorMessage(error.message);
    },
    onSuccess: () => {
      setConnectionStatus('connected');
    },
  });

  const timeoutId = setTimeout(() => {
    if (connectionStatusRef.current === 'connecting') {
      setConnectionStatus('error');
      setErrorMessage('Connection timeout');
    }
  }, 10000);

  cleanupRef.current = cleanup;

  return () => {
    clearTimeout(timeoutId);
    if (cleanupRef.current) {
      cleanupRef.current();
    }
    if (animationTimeoutRef.current) {
      clearTimeout(animationTimeoutRef.current);
    }
  };
}, [streamerId, displayResult]);
```

**修正案2: タイムアウトIDをrefで管理する**
```typescript
const connectionTimeoutRef = useRef<ReturnType<typeof setTimeout> | null>(null);

const resetConnectionTimeout = () => {
  if (connectionTimeoutRef.current) {
    clearTimeout(connectionTimeoutRef.current);
  }
  connectionTimeoutRef.current = setTimeout(() => {
    setConnectionStatus('error');
    setErrorMessage('Connection timeout');
  }, 10000);
};

useEffect(() => {
  const cleanup = subscribeToGachaResults(streamerId, (payload) => {
    if (payload.type === 'gacha' && payload.card) {
      displayResult({
        card: payload.card as unknown as Card,
        userTwitchUsername: payload.userTwitchUsername,
      });
    }
  }, {
    onError: (error) => {
      resetConnectionTimeout(); // タイムアウトをリセット
      setConnectionStatus('error');
      setErrorMessage(error.message);
    },
    onSuccess: () => {
      if (connectionTimeoutRef.current) {
        clearTimeout(connectionTimeoutRef.current);
        connectionTimeoutRef.current = null;
      }
      setConnectionStatus('connected');
    },
  });

  resetConnectionTimeout();

  cleanupRef.current = cleanup;

  return () => {
    if (connectionTimeoutRef.current) {
      clearTimeout(connectionTimeoutRef.current);
    }
    if (cleanupRef.current) {
      cleanupRef.current();
    }
    if (animationTimeoutRef.current) {
      clearTimeout(animationTimeoutRef.current);
    }
  };
}, [streamerId, displayResult]);
```
