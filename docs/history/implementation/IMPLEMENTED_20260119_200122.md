## 概要

---

## 修正内容

### 関数名のキャメルケース修正

**ファイル**: `src/lib/csrf.ts`

**問題点**: 
- 関数名がキャメルケースに従っていない（`hashIp`）

**修正内容**:
```typescript
// 修正前:
export function hashIp(ip: string | null): string {
  if (!ip) return 'unknown'
  return createHash('sha256').update(ip).digest('hex').substring(0, 8)
}

// 修正後:
export function hashIP(ip: string | null): string {
  if (!ip) return 'unknown'
  return createHash('sha256').update(ip).digest('hex').substring(0, 8)
}
```

**使用箇所の修正**:
- Line 138: `ip: hashIP(request.headers.get('x-forwarded-for'))`
- Line 193: `ipHash: hashIP(request.headers.get('x-forwarded-for'))`
