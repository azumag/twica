## 重大な問題点の修正（Critical）

### SESSION cookieのhttpOnly属性をtrueに修正

**変更内容**:
- `src/lib/csrf.ts:100行目` - setCSRFToken()関数内のSESSION cookie設定でhttpOnlyをfalse→trueに修正
- `src/lib/csrf.ts:230行目` - clearCSRFToken()関数内のSESSION cookie設定でhttpOnlyをfalse→trueに修正

**理由**:
SESSION cookieはセッションデータ（ユーザーID、ユーザー名、認証情報など）を含んでいます。httpOnly属性がfalseの場合、JavaScriptからアクセス可能になり、XSS攻撃時に窃取される可能性があります。セッションハイジャックのリスクを防ぐため、httpOnlyはtrueであるべきです。

**修正コード**:
```typescript
// setCSRFToken() (100行目)
cookieStore.set(COOKIE_NAMES.SESSION, JSON.stringify(updatedSession), {
  httpOnly: true,  // ✅ falseからtrueに修正
  secure: process.env.NODE_ENV === 'production',
  sameSite: 'lax',
  path: '/',
  maxAge: SESSION_CONFIG.MAX_AGE_SECONDS,
})

// clearCSRFToken() (230行目)
cookieStore.set(COOKIE_NAMES.SESSION, JSON.stringify(sessionWithoutCsrf), {
  httpOnly: true,  // ✅ falseからtrueに修正
  secure: process.env.NODE_ENV === 'production',
  sameSite: 'lax',
  path: '/',
  maxAge: SESSION_CONFIG.MAX_AGE_SECONDS,
})
```

**確認事項**:
- CSRF_TOKEN cookieのhttpOnlyは`false`のまま維持
- 他のcookie属性（secure, sameSite, path, maxAge）は変更なし
