## 修正内容

### 1. CSRF_TOKEN_SALTの環境変数設定を必須化

**問題:** 重要度: High - `src/lib/csrf.ts` で `process.env.CSRF_TOKEN_SALT || 'default-salt'` となっており、本番環境で salt が設定されていない場合に脆弱なデフォルト値が使用される。

**修正場所:** src/lib/csrf.ts:31-44

**修正内容:**
```typescript
export function hashToken(token: string): string {
  const salt = process.env.CSRF_TOKEN_SALT

  if (!salt) {
    if (process.env.NODE_ENV === 'production') {
      throw new Error('CSRF_TOKEN_SALT environment variable is required in production')
    }

    logger.warn('CSRF_TOKEN_SALT is not set, using default salt. Please set CSRF_TOKEN_SALT in your .env file')
    return createHash('sha256').update(token + 'default-salt').digest('hex')
  }

  return createHash('sha256').update(token + salt).digest('hex')
}
```

**期待される動作:**
- 本番環境（`NODE_ENV === 'production'`）で環境変数が設定されていない場合、エラーをスロー
- 開発環境では警告ログを出力しつつデフォルト値を許容

### 2. tests/unit/upload.test.tsのTypeScript型エラーを修正

**問題:** `mockCookies.mockResolvedValue()` で `set` と `delete` プロパティが含まれていたため、型エラーが発生していた。

**修正場所:** tests/unit/upload.test.ts:30-34

**修正内容:**
```typescript
// 修正前
mockCookies.mockResolvedValue({
  get: vi.fn().mockReturnValue(undefined),
  set: vi.fn(),
  delete: vi.fn(),
} as unknown as ReturnType<typeof cookies>)

// 修正後
mockCookies.mockResolvedValue({
  get: vi.fn().mockReturnValue(undefined),
} as unknown as Awaited<ReturnType<typeof cookies>>)
```

## 技術仕様

### HttpOnly Cookie Pattern

**アーキテクチャ**:
- セッション（httpOnly cookie）: CSRFトークンのハッシュを保存
- CSRFトークン（httpOnly cookie）: トークン自体を保存（JavaScriptからアクセス不可）
- ブラウザが自動的にトークンをリクエストに含める

**セキュリティ機能**:
- 楽観的ロックによる競合状態対策
- timingSafeEqualによるタイミング攻撃対策
- セッション有効期限チェック
- トークン長の検証
- IPアドレスのハッシュ化（セキュリティ配慮）
- URLのサニタイズ（セキュリティ配慮）
- 詳細なログ記録とSentryによるセキュリティエラー報告
- **CSRF_TOKEN_SALTの環境変数必須化（今回の修正）**

**多層防御**:
- 第1層: SameSite='lax' - ブラウザレベルでのクロスサイトPOST阻止
- 第2層: HttpOnly Cookie - XSS攻撃時のトークン窃取防止
- 第3層: トークン検証 - ハッシュ比較によるトークンの正当性確認
