### B1: Race Condition Fix Not Applied in Code Example

**問題:** `docs/ARCHITECTURE.md` の `setCSRFToken()` 関数のコード例に脆弱性がありました。

**修正前:**
```typescript
if (session.csrfTokenHash) {
  const existingToken = getCSRFTokenFromCookie(cookieStore)
  if (existingToken) {
    return existingToken
  }
}
```

**修正後:**
```typescript
const existingToken = getCSRFTokenFromCookie(cookieStore)
if (session.csrfTokenHash && existingToken) {
  return existingToken
}
```

**効果:**
- TOCTOU (Time-Of-Check to Time-Of-Use) 脆弱性を修正
- セッションチェックと cookie 読み取りの間の競合状態を回避

const { csrfTokenHash: _, ...sessionWithoutCsrf } = session

**効果:**

### 追加の修正

#### 1. hashToken 関数のソルト機能

**修正前:**
```typescript
function hashToken(token: string): string {
  return crypto.createHash('sha256').update(token).digest('hex')
}
```

**修正後:**
```typescript
function hashToken(token: string): string {
  const salt = process.env.CSRF_TOKEN_SALT || 'default-salt'
  return crypto.createHash('sha256').update(token + salt).digest('hex')
}
```

**効果:**
- レインボーテーブル攻撃を防止
- 環境変数によるソルトのカスタマイズが可能

#### 2. getCSRFTokenFromCookie 関数の修正

  return tokenCookie || null

#### 4. validateCSRFToken 関数のエラーハンドリング改善

**修正前:**
```typescript
} catch (error) {
  // timingSafeEqualはバッファ長不一致でエラーをスロー
  logger.warn('CSRF validation failed: Hash comparison error', {
    userId: session.twitchUserId,
    error: error instanceof Error ? error.message : String(error),
  })
  return { valid: false, error: ERROR_MESSAGES.CSRF_TOKEN_INVALID }
}
```

**修正後:**
```typescript
} catch (error) {
  if (error instanceof Error && error.name === 'RangeError') {
    logger.warn('CSRF validation failed: Buffer length mismatch', {
      userId: session.twitchUserId,
    })
  } else {
    logger.error('CSRF validation failed: Unexpected error', {
      userId: session.twitchUserId,
      error: error instanceof Error ? error.message : 'Unknown error',
    })
  }

  return { valid: false, error: ERROR_MESSAGES.CSRF_TOKEN_INVALID }
}
```

**効果:**
- RangeError を個別に処理
- 予期しないエラーを ERROR レベルで記録

#### 5. hashIP と sanitizeURL 関数の追加

**追加内容:**
```typescript
export function hashIP(ip: string | null): string {
  if (!ip) return 'unknown'
  return crypto.createHash('sha256').update(ip).digest('hex').substring(0, 8)
}

export function sanitizeURL(url: string): string {
  try {
    const urlObj = new URL(url)
    return urlObj.pathname
  } catch {
    return 'invalid_url'
  }
}
```

**効果:**
- IP アドレスのハッシュ化（先頭 8 文字のみ）による情報漏洩防止
- URL のサニタイズ（パスのみ）
