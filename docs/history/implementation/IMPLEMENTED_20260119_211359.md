## 実装内容

### 1. CSRFトークン管理モジュール (`src/lib/csrf.ts`)

実装された関数：
- `generateCSRFToken()`: 暗号学的に安全なCSRFトークンを生成（32 bytes = 256 bits）
- `hashToken(token)`: SHA-256ハッシュを生成（CSRF_TOKEN_SALTを使用）
- `setCSRFToken()`: セッションにCSRFトークンのハッシュを保存し、トークン自体はhttpOnly cookieに保存
- `validateCSRFToken(request)`: CSRFトークンを検証（ハッシュ比較）
- `clearCSRFToken()`: CSRFトークンをクリア
- `hashIP(ip)`: IPアドレスをハッシュ化（セキュリティログ用）
- `sanitizeURL(url)`: URLをサニタイズ（セキュリティログ用）

セキュリティ機能：
- **HttpOnly Cookie Pattern**: トークンはhttpOnly cookieに保存され、JavaScriptからアクセス不可
- **ハッシュ比較**: セッションにはトークンのハッシュのみを保存（トークン値の漏洩防止）
- **タイミング攻撃対策**: `timingSafeEqual` による安全な比較
- **楽観的ロック**: セッションにバージョン番号を追加し、競合状態を回避
- **CSRF_TOKEN_SALT 検証**: 本番環境では必須、開発環境では警告ログとデフォルト値

### 2. 定数 (`src/lib/constants.ts`)

## セキュリティ機能

### 多層防御
1. **第1層**: SameSite='lax' - ブラウザレベルでのクロスサイトPOST阻止
2. **第2層**: HttpOnly Cookie - XSS攻撃時のトークン窃取防止
3. **第3層**: Originヘッダー検証 - 不正なオリジンからのリクエストをブロック
4. **第4層**: トークン検証 - ハッシュ比較によるトークンの正当性確認

### 楽観的ロック
- セッションにバージョン番号を追加
- トークン生成時にバージョンを検証
- バージョンが不一致の場合、リトライ（最大3回、50ms間隔）
- 更新成功時にバージョンをインクリメント

### セキュリティ配慮のあるログ記録
- IPアドレスのSHA-256ハッシュ化（先頭8文字のみ）
- エンドポイントURLのサニタイズ（パスのみ）
- タイムスタンプのISO 8601形式記録
- ユーザーIDの記録（デバッグ用）

## レビュー対応内容

### CSRF_TOKEN_SALT の扱い
- 本番環境では未設定時にエラーをスロー
- 開発環境では警告ログを出力しつつデフォルト値を使用

### エラーハンドリング
- クライアントへのエラーメッセージは汎用的に（ERROR_MESSAGES.CSRF_TOKEN_INVALID）
- ログメッセージは詳細に（検証失敗の理由、IP、ユーザーIDなど）
