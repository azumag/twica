### レビューからの修正内容

#### 1. `src/lib/realtime.ts` の修正

**修正1: 再接続ロジックのタイマー管理バグの修正**

新しい再接続を開始する前に、既存の `retryTimeout` がクリアされない問題を修正：

```typescript
const subscribe = () => {
  // 既存のタイマーをクリア
  if (retryTimeout) {
    clearTimeout(retryTimeout)
    retryTimeout = null
  }

  try {
    client = getSupabaseRealtimeClient()
    // ...
  }
}
```

**修正2: 未対応のWebSocket接続ステータスへの対応**

接続ステータスのチェックを `SUBSCRIBED`, `CLOSED`, `CHANNEL_ERROR` のみから、すべてのステータスに対応するように修正：

```typescript
.subscribe((status, err) => {
  if (status === 'SUBSCRIBED') {
    isSubscribed = true
    retryCount = 0
    logger.info(`Successfully subscribed to gacha:${streamerId}`)
    onSuccess?.()
  } else {
    // SUBSCRIBED以外はすべてエラーとして扱う
    logger.warn(`Connection issue for gacha:${streamerId}, status: ${status}`)
    isSubscribed = false

    const error: RealtimeError = {
      type: 'connection',
      message: `Realtime connection issue: ${status}`,
      error: err,
    }

    logger.error(`Realtime error for streamer ${streamerId}:`, error)
    reportRealtimeError(err, {
      action: 'subscribe',
      streamerId,
      status,
      retryCount,
    })

    onError?.(error)

    if (retryCount < maxRetries) {
      retryCount++
      const delay = getRetryDelay(retryCount, retryDelay)
      logger.info(`Retrying connection (attempt ${retryCount}/${maxRetries}) in ${Math.round(delay)}ms...`)
      retryTimeout = setTimeout(subscribe, delay)
    } else {
      logger.error(`Max retries (${maxRetries}) reached for gacha:${streamerId}`)
      const maxRetriesError: RealtimeError = {
        type: 'connection',
        message: 'Max retries reached. Please refresh the page to reconnect.',
        error: null,
      }
      onError?.(maxRetriesError)
    }
  }
})
```

**修正3: TypeScriptの型定義のプラットフォーム依存の修正**

`NodeJS.Timeout` 型を使用しているが、この型はNode.js環境に特化しており、ブラウザ環境では正しく動作しない可能性があるため修正：

```typescript
// 修正前
let retryTimeout: NodeJS.Timeout | null = null

// 修正後
let retryTimeout: ReturnType<typeof setTimeout> | null = null
```

**修正4: 再接続戦略の改善（指数バックオフとジッターの導入）**

固定遅延（3秒）から指数バックオフとジッターを使用した再接続戦略に変更：

```typescript
const getRetryDelay = (retryCount: number, baseDelay: number): number => {
  const backoffDelay = Math.min(baseDelay * Math.pow(2, retryCount), 30000) // 最大30秒
  const jitter = Math.random() * 1000 // 最大1秒のジッター
  return backoffDelay + jitter
}

// 使用時
retryTimeout = setTimeout(subscribe, getRetryDelay(retryCount, retryDelay))
```

**修正5: 最大再接続回数到達時のユーザー通知**

最大再接続回数に到達した場合、ログに記録されるだけであり、ユーザーには通知されない問題を修正：

```typescript
} else {
  logger.error(`Max retries (${maxRetries}) reached for gacha:${streamerId}`)
  const maxRetriesError: RealtimeError = {
    type: 'connection',
    message: 'Max retries reached. Please refresh the page to reconnect.',
    error: null,
  }
  onError?.(maxRetriesError)
}
```
