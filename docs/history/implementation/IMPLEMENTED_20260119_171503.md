# 実装済み機能のドキュメント

このドキュメントは、プロジェクトで実装済みの機能と変更履歴を記録するものです。

## CSRF保護のHttpOnly Cookieパターンへの移行 (2026-01-19)

### 変更内容
1. CSRF_TOKEN cookieをhttpOnly=trueに変更（src/lib/csrf.ts:109）
2. validateCSRFToken()でX-CSRF-Tokenヘッダーを使用しないように修正（src/lib/csrf.ts:156）
3. ログレベルの適正化（情報不足によるエラーをINFO、攻撃の疑いをINFOからINFOに調整）
4. src/lib/csrf.ts:39のコメントを修正（「非httpOnly cookie」→「httpOnly cookie」）

### 理由
- XSS脆弱性がある場合でも、CSRFトークンがJavaScriptからアクセスできないことで安全性を確保
- SameSite='lax'によりOAuthコールバックを許可しつつ、クロスサイトPOSTリクエストをブロック
- クライアント側の実装が簡素化される
