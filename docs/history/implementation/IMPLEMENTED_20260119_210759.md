# CSRF保護の実装（HttpOnly Cookie Pattern）

**日時:** 2026-01-19
**設計書:** docs/ARCHITECTURE.md

## 概要

設計書 `docs/ARCHITECTURE.md` に基づいて、HttpOnly Cookie Patternを使用したCSRF保護機能を実装しました。

## 実装内容

### 1. Phase 1: 基礎コンポーネントの実装

#### 1.1 CSRFトークン管理モジュール
- **ファイル**: `src/lib/csrf.ts`
- **実装内容**:
  - `generateCSRFToken()`: 暗号学的に安全な乱数でCSRFトークンを生成
  - `hashToken()`: SHA-256ハッシュ生成（ソルト付き）
  - `setCSRFToken()`: セッションにトークンハッシュを保存し、httpOnly cookieにトークンを保存
  - `validateCSRFToken()`: httpOnly cookieからのトークン検証
  - `clearCSRFToken()`: トークンの削除と無効化
  - `hashIP()`: IPアドレスのハッシュ化（セキュリティ配慮）
  - `sanitizeURL()`: URLのサニタイズ（セキュリティ配慮）
  - 楽観的ロックによる競合状態対策（バージョン管理）

#### 1.2 定数の追加
- **ファイル**: `src/lib/constants.ts`
- **実装内容**:
  - `CSRF_CONFIG`: トークン長、リトライ設定、許可オリジン
  - `SESSION_CONFIG`: セッション有効期間
  - `SESSION_COOKIE_OPTIONS`: Cookie設定（httpOnly, sameSite='lax'）
  - `COOKIE_NAMES.CSRF_TOKEN`: CSRFトークンcookie名
  - `ERROR_MESSAGES.CSRF_TOKEN_INVALID`: CSRFエラーメッセージ

#### 1.3 単体テスト
- **ファイル**: `tests/unit/csrf.test.ts`
- **実装内容**:
  - 16件のテストケースを実装
  - hashToken, setCSRFToken, validateCSRFToken, clearCSRFToken, hashIP, sanitizeURLのテスト
  - すべてのテストがパス

## 技術仕様

### HttpOnly Cookie Pattern

**アーキテクチャ**:
- セッション（httpOnly cookie）: CSRFトークンのハッシュを保存
- CSRFトークン（httpOnly cookie）: トークン自体を保存（JavaScriptからアクセス不可）
- ブラウザが自動的にトークンをリクエストに含める

**セキュリティ機能**:
- 楽観的ロックによる競合状態対策
- timingSafeEqualによるタイミング攻撃対策
- セッション有効期限チェック
- トークン長の検証
- IPアドレスのハッシュ化（セキュリティ配慮）
- URLのサニタイズ（セキュリティ配慮）
- 詳細なログ記録とSentryによるセキュリティエラー報告

**多層防御**:
- 第1層: SameSite='lax' - ブラウザレベルでのクロスサイトPOST阻止
- 第2層: HttpOnly Cookie - XSS攻撃時のトークン窃取防止
- 第3層: トークン検証 - ハッシュ比較によるトークンの正当性確認
