## 概要

CSRF保護機能の設計書と実装内容について厳しくレビューを実施しました。計10件の問題が発見されました。

### 結論

**重大な問題あり（Critical: 4件）**

**QA前の対応が必要**: 実装エージェントに修正を依頼

## Critical - 重大な問題

### 1. docs/ARCHITECTURE.md:412 - 変数名バグ

**問題**: `requestTokenHash` が2回使用されており、`sessionTokenHash` との比較になっていない

**該当コード**:
```typescript
const requestTokenHash = hashToken(requestToken)
const sessionBuffer = Buffer.from(sessionTokenHash)
const requestBuffer = Buffer.from(requestTokenHash)  // ← requestTokenHashを再使用
```

**修正案**: 2行目を `const requestBuffer = Buffer.from(requestToken)` に変更

---

### 2. docs/ARCHITECTURE.md:290-294 - セッション期限チェックの論理エラー

**問題**: `currentSession.expiresAt` をチェックすべきが、`session.expiresAt` をチェックしている（古い値）

**該当コード**:
```typescript
// Check session expiration before version validation
if (currentSession.expiresAt && Date.now() > currentSession.expiresAt) {  // ← session.expiresAtであるべき
  throw new Error('Session expired')
}
```

**修正案**: `if (currentSession.expiresAt && Date.now() > currentSession.expiresAt)` に変更

---

### 3. docs/ARCHITECTURE.md:298 - 楽観的ロックの不整合

**問題**: `session.version + 1` を使用しているが、`currentSession` を使用すべき

**該当コード**:
```typescript
const updatedSession = { ...session, csrfTokenHash: tokenHash, version: session.version + 1 }
```

**修正案**: `version: currentSession.version + 1` に変更

---

### 4. docs/IMPLEMENTED.md:158-159 と docs/ARCHITECTURE.md 間の不整合

**問題**: IMPLEMENTED.mdではOrigin/Referer検証を削除と記載しているが、ARCHITECTURE.md:362-398にはまだ存在

**修正案**: 両ドキュメントを同期 - Origin/Referer検証をARCHITECTURE.mdからも削除するか、IMPLEMENTED.mdを修正

---

## High - 重要な問題

### 5. docs/ARCHITECTURE.md:269-270 - session変数の不使用

**問題**: `userId` を `session.twitchUserId` から取得後、その場で使用されていない

**該当コード**:
```typescript
const session = parseSession(sessionCookie)
const userId = session.twitchUserId  // ← 使用されていない

const existingToken = getCSRFTokenFromCookie(cookieStore)
if (session.csrfTokenHash && existingToken) {
  return existingToken
}
```

**修正案**: `userId` を使用するか、変数を削除

---

### 6. docs/ARCHITECTURE.md:282-287 - 重複コード

**問題**: セッション取得ロジックが269行目と重複

**該当コード**:
```typescript
// 269行目
const sessionCookie = cookieStore.get(COOKIE_NAMES.SESSION)?.value
if (!sessionCookie) {
  throw new Error('No session found')
}
const session = parseSession(sessionCookie)

// 282行目（重複）
const currentSessionCookie = cookieStore.get(COOKIE_NAMES.SESSION)?.value
if (!currentSessionCookie) {
  throw new Error('No session found')
}
const currentSession = parseSession(currentSessionCookie)
```

**修正案**: 関数化して再利用
