### 2. CSRF_TOKEN_SALT のデフォルト値

**問題箇所:** ARCHITECTURE.md:254

```typescript
const salt = process.env.CSRF_TOKEN_SALT || 'default-salt'
```

**問題点:** 本番環境で `default-salt` が使用されると、攻撃者にトークンハッシュの解析を容易にする

**対応状況:** IMPLEMENTED.md で修正済み (src/lib/csrf.ts:21-34)

**現在の実装:**

```typescript
export function hashToken(token: string): string {
  const salt = process.env.CSRF_TOKEN_SALT

  if (!salt) {
    if (process.env.NODE_ENV === 'production') {
      throw new Error('CSRF_TOKEN_SALT environment variable is required in production')
    }

    logger.warn('CSRF_TOKEN_SALT is not set, using default salt...')
    return createHash('sha256').update(token + 'default-salt').digest('hex')
  }

  return createHash('sha256').update(token + salt).digest('hex')
}
```

**評価:** ✅ 適切に修正されている

## セキュリティ (Security)

### 評価: 良好 ✅

- 第1層: SameSite='lax' - ブラウザレベルでクロスサイトPOST阻止
- 第2層: HttpOnly Cookie - XSS攻撃時のトークン窃取防止
- 第3層: トークン検証 - ハッシュ比較による正当性確認
- 第4層: Origin/Referer ヘッダー検証

**適切なセキュリティ対策:**
- `timingSafeEqual` によるタイミング攻撃対策 ✅
- IPアドレスのSHA-256ハッシュ化 (先頭8文字のみ) ✅
- URLパスのみのサニタイズ ✅
- セッション有効期限チェック ✅
- トークン長の検証 ✅
- Sentryへのセキュリティエラー報告 ✅

**改善提案:**

1. **CSRF_TOKEN_SALT の要件を明確に**

   設計書にsaltの最小長と複雑性の要件を追加:

   ```typescript
   // 推奨: constants.ts に追加
   ```

## コードの簡潔性 (Code Simplicity)

### 1. 高階関数のオーバーヘッド ⚠️

**問題箇所:** ARCHITECTURE.md:509-530 (src/lib/middleware/csrf.ts)

```typescript
export async function withCSRFProtection(
  handler: (request: NextRequest) => Promise<NextResponse>
): Promise<NextResponse> {
  return async (request: NextRequest) => {
    const method = request.method.toUpperCase()

    if (['POST', 'PUT', 'DELETE'].includes(method)) {
      const validation = await validateCSRFToken(request)
      if (!validation.valid) {
        return NextResponse.json({ error: ERROR_MESSAGES.FORBIDDEN }, { status: 403 })
      }
    }

    return handler(request)  // 追加の非同期オーバーヘッド
  }
}
```

**問題点:**
- すべてのリクエストに対して高階関数が呼び出される
- `handler(request)` で追加のスタックフレーム
- Next.js Middleware を使うべき (より効率的)

**推奨実装:**

```typescript
// src/middleware.ts (Next.js Middleware)
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'
import { validateCSRFToken } from '@/lib/csrf'

export async function middleware(request: NextRequest) {
  const method = request.method.toUpperCase()

  // POST/PUT/DELETEのみ検証
  if (['POST', 'PUT', 'DELETE'].includes(method)) {
    const validation = await validateCSRFToken(request)

    if (!validation.valid) {
      return NextResponse.json(
        { error: 'Forbidden' },
        { status: 403 }
      )
    }
  }

  return NextResponse.next()
}

export const config = {
  matcher: ['/api/:path*'],  // APIルートのみに適用
}
```

**評価:** ⚠️ 設計が複雑 - Middleware への移行を推奨

```typescript
    // エラーログ...
```

```typescript
export async function validateCSRFToken(request: Request): Promise<{ valid: boolean; error?: string }> {
  const cookieStore = await cookies()
  const sessionCookie = cookieStore.get(COOKIE_NAMES.SESSION)?.value

  if (!sessionCookie) {
    return { valid: false, error: ERROR_MESSAGES.CSRF_TOKEN_INVALID }
  }

  const session = parseSession(sessionCookie)

  // セッション検証をまとめる
  const now = Date.now()
  if (session.expiresAt && now > session.expiresAt) {
    return { valid: false, error: ERROR_MESSAGES.CSRF_TOKEN_INVALID }
  }

  if (!session.csrfTokenHash) {
    return { valid: false, error: ERROR_MESSAGES.CSRF_TOKEN_INVALID }
  }

  // 検証ロジック...
}
```

## 潜在的なバグとエッジケース

### 1. 楽観的ロックの境界条件

**問題箇所:** ARCHITECTURE.md:294-298

```typescript
if (currentSession.version !== session.version) {
  throw new Error('CSRF token generation failed: Concurrent modification detected')
}
```

**潜在的な問題:**
- セッションCookieの取得と解析の間に別リクエストが更新する可能性
- 現時点では RETRY_DELAY_MS が設定されていない

**現在の実装 (IMPLEMENTED.md ベース):**

```typescript
// setCSRFToken 内で
const updatedSession = { ...session, csrfTokenHash: tokenHash, version: session.version + 1 }
cookieStore.set(COOKIE_NAMES.SESSION, JSON.stringify(updatedSession), SESSION_COOKIE_OPTIONS)
```

**改善提案:**

```typescript
// 定数に追加
export const CSRF_CONFIG = {
  MAX_RETRY_COUNT: 3,
  RETRY_DELAY_MS: 50,  // 50ms
  // ...
} as const

// リトライロジック
let currentVersion = session.version
for (let attempt = 0; attempt < CSRF_CONFIG.MAX_RETRY_COUNT; attempt++) {
  const freshSession = parseSession(cookieStore.get(COOKIE_NAMES.SESSION)?.value)

  if (freshSession.version !== currentVersion) {
    if (attempt === CSRF_CONFIG.MAX_RETRY_COUNT - 1) {
      throw new Error('CSRF token generation failed: Max retries exceeded')
    }
    await sleep(CSRF_CONFIG.RETRY_DELAY_MS)
    currentVersion = freshSession.version
    continue
  }

  // 更新...
  break
}
```
