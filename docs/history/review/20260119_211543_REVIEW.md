## セキュリティ (Security)

### 評価: 良好 ✅

**多層防御の設計:**

| レイヤー | 対策 | 状態 |
|----------|------|------|
| 第1層 | SameSite='lax' - ブラウザレベルでクロスサイトPOST阻止 | ✅ |
| 第2層 | HttpOnly Cookie - XSS攻撃時のトークン窃取防止 | ✅ |
| 第3層 | Origin/Referer ヘッダー検証 | ✅ |
| 第4層 | トークン検証 - ハッシュ比較による正当性確認 | ✅ |

**適切なセキュリティ対策:**

- 暗号学的に安全な乱数使用 (`crypto.randomBytes(32)`) ✅
- SHA-256 ハッシュ化 ✅
- `timingSafeEqual` によるタイミング攻撃対策 ✅
- IPアドレスのSHA-256ハッシュ化（先頭8文字のみ）✅
- URLパスのみのサニタイズ ✅
- セッション有効期限チェック ✅
- トークン長の検証 ✅
- Sentryへのセキュリティエラー報告 ✅

**改善提案（オプション）:**

1. **CSRF_TOKEN_SALT の要件を明確に**

   設計書にsaltの最小長と複雑性の要件を追加することを推奨:

   ```typescript
   // 推奨: constants.ts に追加
   export const CSRF_TOKEN_REQUIREMENTS = {
     MIN_LENGTH: 32,  // 最低32文字
   } as const
   ```

2. **レート制限の追加（オプション）**

   CSRF検証失敗が短時間に多数発生した場合、一時的にIPをブロックすることを検討:

   ```typescript
   // src/lib/csrf-rate-limiter.ts (新規 - オプション)
   import { Ratelimit } from '@upstash/ratelimit'
   import { Redis } from '@upstash/redis'

   const csrfRatelimit = new Ratelimit({
     redis: Redis.fromEnv(),
     limiter: Ratelimit.slidingWindow(10, '1 m'),  // 1分あたり10回
   })

   export async function checkCSRFRateLimit(ip: string): Promise<boolean> {
     const { success } = await csrfRatelimit.limit(ip)
     return success
   }
   ```

## コードの簡潔性 (Code Simplicity)

### 評価: 良好 ✅

**高階関数の使用（許容範囲）**

**問題箇所:** ARCHITECTURE.md:509-530 (src/lib/middleware/csrf.ts)

設計書では高階関数 (`withCSRFProtection`) を使用していますが、これは許容範囲です：

- すべてのリクエストに対して高階関数が呼び出されるが、検証はPOST/PUT/DELETEのみ
- Next.js Middleware の方が効率的だが、高階関数でも十分機能する
- 既存のコードとの互換性を維持

**評価:** ⚠️ 許容範囲 - 改善は可能だが必須ではない

**定数の重複定義（問題なし）**

設計書で `SESSION_COOKIE_OPTIONS` の定義が分散していますが、IMPLEMENTED.md によると実装では `src/lib/constants.ts` で一元管理されています。

**評価:** ✅ 実装で適切に管理されている

**改善提案（オプション）:**

1. **Origin許可リストを Set 化（パフォーマンス向上）**

   ```typescript
   // ARRAY は線形検索 O(n)
   const allowedOrigins = [
     process.env.NEXT_PUBLIC_APP_URL || 'http://localhost:3000',
     ...(process.env.NODE_ENV === 'development' ? ['http://127.0.0.1:3000'] : []),
   ]

   // SET は高速検索 O(1)
   const allowedOriginsSet = new Set(allowedOrigins)
   if (origin && !allowedOriginsSet.has(origin)) {
     // ...
   ```
