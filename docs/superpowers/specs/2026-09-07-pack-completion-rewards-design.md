# パックコンプ報酬（#720）

2026-09-07 ユーザー承認済み。子 Issue #730–734 の仕様を採用する。
特別カードを全体・パックのコンプリート判定の分子・分母から除外する。
報酬は同一配信者の inactive カードのみ。設定中の active 化は DB で拒否する。
閲覧時に現在の active 全種類の所有を確認し、1ユーザー1パック1回のみ付与する。
0枚パックは対象外。発行上限は適用しない。未取得の報酬詳細はクライアントへ送らない。

現行 docs/db-driver-migration.md が正本。PlanetScale の単一接続を使用し、
廃止された PostgREST を追加しない。migration は PlanetScale 用の履歴へ追加する。
DB 更新待ち・付与失敗で既存コレクションを壊さない。設定操作は未保存を明示する。
設定と付与は原子的な RPC とし、設定変更中の古いキャッシュからの付与も DB で再検証する。

配信者: パック管理で設定・解除、遡及付与と受領済み人数を説明する。
孤立設定を解除できるようカード管理にも入口を置く。
視聴者: none / locked / grantedNow / granted。locked はパック名・レアリティのみ。
獲得演出はパック別に順次表示し、閉じる・Esc・背景クリックに対応する。
375px では縦積み。報酬の所有カードは通常 grid にコンプ報酬バッジで表示する。
名前の再利用は古い付与記録と衝突するため非推奨。カード交換・消費後も再付与しない。

検証: 純関数、API 認証/CSRF/権限、実 PostgreSQL の原子性/並行性、UI、型、lint、
既存コンプの回帰。preview 配備と画面確認後に main/production のゲートを適用する。
