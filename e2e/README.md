# TwiCa E2E テストシナリオ

PR #303 で追加・変更された機能に対するE2Eテストシナリオです。

## ディレクトリ構成

```
e2e/
├── README.md               # このファイル
├── support-plan.md         # 支援特典機能（コードアクティベーション・特典解除・特典ページ）
└── support-inquiries.md    # 支援者向け問い合わせフォーム
```

## テストID 体系

| 範囲 | ID範囲 | 内容 |
|---|---|---|
| 支援特典 | TC-1001〜TC-1199 | 特典ページ・コードアクティベーション・ストレージ |
| 問い合わせ | TC-1401〜TC-1599 | 支援者向け問い合わせフォーム |

## 実行環境

```
本番URL: https://twica.bluemoon.works/
ツール: agent-browser
```

## 認証が必要なテスト

認証が必要なテストケース（TC-11xx, TC-12xx, TC-14xx）は以下のセットアップが必要です：

```bash
# 視聴者（素地）
/e2e-test --env production --setup-auth viewer

# 支援者（supporter/patron）
/e2e-test --env production --setup-auth supporter
```
