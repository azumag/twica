# TwiCa E2E テストシナリオ

PR #303 で追加・変更された機能に対するE2Eテストシナリオです。

## ディレクトリ構成

```
e2e/
├── README.md               # このファイル
├── support-plan.md         # 支援プラン機能（コードアクティベーション・ダウングレード・プランページ）
├── discord-integration.md  # Discord連携機能
└── support-inquiries.md    # 支援者向け問い合わせフォーム
```

## テストID 体系

| 範囲 | ID範囲 | 内容 |
|---|---|---|
| 支援プラン | TC-1001〜TC-1199 | プランページ・コードアクティベーション・ストレージ |
| Discord連携 | TC-1201〜TC-1399 | Discord連携・Twitchサブスクプラン |
| 問い合わせ | TC-1401〜TC-1599 | 支援者向け問い合わせフォーム |

## 実行環境

```
本番URL: https://twica.bluemoon.works/
ツール: agent-browser
```

## 認証が必要なテスト

認証が必要なテストケース（TC-11xx, TC-12xx, TC-14xx）は以下のセットアップが必要です：

```bash
# 視聴者（ベーシックプラン）
/e2e-test --env production --setup-auth viewer

# 支援者（supporter/patron プラン）
/e2e-test --env production --setup-auth supporter
```
